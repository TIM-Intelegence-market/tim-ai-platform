# TIM V2 Vision

TIM V2 is a versioned, evidence-first research and decision platform built on
the frozen TIM Core and TIM Intelligence Manager foundations.

Its purpose is to turn observed market, Research and Evaluation evidence into
reproducible knowledge and explicitly gated decisions without allowing model
interpretation to become an unverified canonical fact or an uncontrolled
trading action.

TIM V2 separates:

- observation from interpretation;
- Research from production decisions;
- features from strategies;
- evaluation from promotion;
- simulation from execution;
- paper, shadow and live operating modes;
- canonical evidence from agent- or model-generated summaries.

Autonomy is earned by evidence and explicit governance gates. It is never the
default.
