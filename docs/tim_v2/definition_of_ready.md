# TIM V2 Definition of Ready

A V2 implementation item is ready only when all applicable checks pass:

- problem statement and non-goals are explicit;
- module owner and reviewers are named;
- decision-log reference exists;
- inputs, outputs and schemas are drafted;
- source and data classification is known;
- temporal semantics and leakage risks are documented;
- trust boundary and threat model are reviewed;
- failure, abstention and degraded modes are defined;
- test fixtures and acceptance criteria are available;
- observability and audit requirements are defined;
- migration, compatibility and rollback paths are documented;
- protected TIM Core/TIM-IM boundaries are identified;
- execution impact is `none` or explicitly gated;
- branch type and version impact are selected;
- no unresolved critical risk blocks implementation.

If any required item is unknown, the work remains planning or discovery.
