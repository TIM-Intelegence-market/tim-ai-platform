# TIM Vision 2030

TIM evolves as a transparent, local-first market research system. Its governing sequence is evidence collection, deterministic observation, reproducible memory, research cases, human explanation, and only then explicitly isolated paper evaluation.

## Milestones

1. **Foundation:** public data, deterministic candles, observations and provenance.
2. **Research:** historical memory, evidence cases, news and authorized knowledge citations.
3. **Context:** independent long-term context and observation-only short-term explanations.
4. **Evaluation:** TEST_ONLY paper journals with forward-only evidence, costs and reproducibility.
5. **Scientific maturity:** dataset governance, holdouts, audit trails, reliability labels and reproducible releases.

## Governance

- Humans control modes, sources and configuration.
- Models explain supplied evidence; they do not create market facts or actions.
- Every conclusion links to provenance, timestamps and rule versions.
- Simulation is never live evidence.
- No API keys, exchange accounts, wallets, real orders or execution paths belong in the research architecture.
- Changes to rules require version increments, tests, changelog entries and validation evidence.

## Evolution gate

A phase advances only when existing tests pass, new behavior is documented, deterministic replay is possible, and remaining uncertainty is visible. Feature count is never a substitute for evidence quality.
