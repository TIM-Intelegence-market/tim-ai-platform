# TIM Core 1.0 — Freeze Declaration

**Status:** FROZEN  
**Operating mode:** OBSERVE-only  
**Purpose:** Deterministic market research  

This document freezes the currently implemented research core. It does not
change runtime behaviour, market rules, thresholds, or validation logic. The
machine-readable source of truth is `config/core_manifest.json`.

## Frozen component set

| Component | Version |
|---|---:|
| AggTrade Persistence | 1.0.0 |
| Orderflow Metrics | 1.0.0 |
| Orderflow Observations | 1.0.0 |
| Orderflow Validation | 1.0.0 |
| Research Analytics | 1.0.0 |
| Dashboard | 2.1.0 |

The dashboard is recorded as `2.1.0` because this is the version declared by
the running implementation at freeze time. Re-labelling it as `2.0.0` would
make the frozen manifest inconsistent with the software being observed.

## Change policy

Allowed changes are limited to:

- fixes for reproducible defects;
- integrity and security corrections;
- documentation and monitoring;
- scientific methodology that does not alter runtime results.

The following are prohibited in Core 1.0:

- new observation rules or data sources;
- threshold changes;
- changes to outcome definitions or validation logic;
- any other functional extension of the research core.

Any necessary functional change requires a new Core version. Data generated by
different Core, rule, metric, or validation versions must never be silently
combined in one analysis.

## Phase 5 release gate

Phase 5 remains locked until recorded evidence demonstrates all of the
following:

1. Sufficient real runtime and documented data coverage.
2. A sufficient number of fully validated orderflow cases.
3. Stable deterministic replay results.
4. Version consistency across the evaluated dataset.
5. No unresolved integrity issue.

There is no automatic unlock. A release decision must cite persisted evidence
and define the next Core version before development resumes.

## Scientific operating principle

TIM Core 1.0 now advances through the quality, coverage, and reproducibility of
observed data—not through additional features. It remains read-only and does
not create orders, trading signals, or execution paths.
